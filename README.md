# Voice Assistance Academic Report Draft

Early Word, PDF and LaTeX report materials for a project about voice technology and digital inclusion.

## Scope and status

This repository contains an outline/introduction and report template material, not a runnable software application. The PDF includes a title page and placeholders; it should not be interpreted as a complete final report or evidence of finished experiments.

## File index

| Path | Contents |
|---|---|
| `rapport/Introduction.docx` | Outline and introductory material |
| `rapport/rapport.pdf` | Existing report PDF/template |
| `rapport/laText code.txt` | Existing LaTeX source text |

Open the Word/PDF documents directly. Inspect the LaTeX text before compiling in your own environment; required assets and a validated build configuration are not provided. The original Office lock file, filenames and history are preserved.
